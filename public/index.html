Multi-Tenant Persistence Architecture

Each user's WhatsApp credentials and bot configurations are isolated in the database by unique session_id and user_id.

  • cortex_users: Stores user email, salt hash, role, and permanent 12-digit UID.
  • whatsapp_sessions: Partitioned Baileys Multi-Device crypto auth keys.
  • bot_configs: Scoped daily morning message and PDF forwarding parameters.
